# 띠 컬러 로드맵 (Zodiac Color Roadmap)

동양 오행(五行)과 컬러 심리학을 결합한 **12띠별 컬러 추천 가이드** 웹앱입니다.
업로드된 PPT(`yivl0k9m9d2zh24.pptx`)의 콘텐츠를 기반으로 제작했습니다.

- 개발자: 박서현
- 기준일: 2026.09.29

---

## 1. 프로젝트 목표

- 태어난 띠(12지지)로 **어울리는 컬러와 피해야 할 컬러**를 즉시 확인
- 전통 오행 이론(상생 · 상극)을 시각적으로 이해할 수 있는 **이론 섹션** 제공
- 12띠 전체를 한눈에 비교하는 **카탈로그**와, 개인 리포트를 보관하는 **아카이브** 제공

## 2. 주요 기능 (구현 완료)

### Step 1 — 띠 찾기
- 출생 연도(1900~2100, 양력 기준) 입력 시 12지지 계산식 `(year - 4) mod 12` 로 띠 자동 판별
- 연도를 모를 경우 12개 띠 칩(🐭 쥐띠 ~ 🐷 돼지띠)으로 직접 선택

### Step 2 — 띠 컬러 리포트
- 띠별 이모지 · 지지(地支) · 대표 오행 배지 표시
- **✓ 어울리는 컬러**: 색상 스와치 + 컬러명 + HEX + 추천 이유
- **✕ 피해야 할 컬러**: 대각선 X 표시 스와치 + 상극 이유 설명 박스
- **＋ 보완하면 좋은 컬러**: 상생(相生) 오행 컬러 3종 — 부족한 기운을 채워주는 보완 컬러와 설명
- **오행 음식 궁합**: 대표 맛(오미) 배지 + 기운을 살리는 음식 / 과하면 좋지 않은 음식 목록 + 설명
- **오행 밸런스 레이더 차트** (Chart.js): 해당 띠의 중심 오행 100점, 상생 오행 62점, 나머지 26점 기준
- **추천 팔레트**: HEX 6종 팔레트, 개별 스와치 클릭 시 해당 HEX 복사
- 팔레트 전체 HEX 한 번에 복사 버튼
- 띠별 맞춤 Tip 박스

### 이론 — 오행(五行)과 컬러
- 목(木)·화(火)·토(土)·금(金)·수(水) 5개 카드 (대표 컬러, 키워드, 계절, 설명)
- **상생(相生)** 순환: 목 → 화 → 토 → 금 → 수 → 목
- **상극(相剋)** 순환: 목 → 토 → 수 → 화 → 금 → 목

### 음식 — 오행별 음식 궁합
- 오행 5종별 카드: 대표 맛(오미), 기운을 살리는 음식, 과하면 기운을 누르는 음식, 설명
- 리포트 카드 안에도 선택한 띠의 오행 기준 음식 궁합 표시
- 참고용 정보 안내 문구 포함

### 카탈로그 — 12띠 전체 컬러 가이드
- PPT 구성 순서 그룹(쥐·돼지 / 소·양 / 호랑이·토끼 / 뱀·닭 / 용 / 말 / 원숭이 / 개)
- 각 카드에 어울림·주의 미니 스와치, 클릭 시 해당 리포트로 이동

### 아카이브 — 저장한 컬러 카드
- 브라우저별 소유 토큰(`owner_token`) 기반으로 카드 저장/목록/삭제
- 각 카드에서 **리포트 보기**, **컬러 코드 복사** 가능
- Table API 사용 불가 시 **localStorage 자동 폴백**으로 동일 기능 유지

### 공통
- 반응형 레이아웃(모바일 390px ~ 데스크톱), 키보드 접근성, `prefers-reduced-motion` 대응
- 토스트 알림, 저장 모달(ESC 닫기 지원)

## 4. 데이터 모델 및 저장소

### 정적 데이터 (`js/data.js`)
- `ELEMENTS`: 오행 5종 메타데이터 (컬러, 상생 `generates`, 상극 `controls`, 보완 `generatedBy` / `controlledBy`, 오미 `taste`, `goodFoods`, `cautionFoods`, `balanceColors`)
- `ZODIAC`: 12띠별 `element`, `good[]`, `bad[]`, `badReason`, `tip`, `palette[]`

### 동적 데이터 — `color_cards` 테이블
RESTful Table API(`tables/color_cards`)로 저장되며, 스키마는 `.tables/schema.json`에 정의됩니다.

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `id` | text | 레코드 고유 ID (시스템 관리) |
| `title` | text | 사용자가 붙인 카드 이름 |
| `zodiac_key` | text | 띠 키 (`rat`, `ox`, `tiger` …) |
| `zodiac_name` | text | 띠 한글 이름 |
| `element` | text | 대표 오행 표기 (예: `수(水)`) |
| `good_hexes` | text | 어울리는 컬러 HEX 목록 (콤마 구분) |
| `bad_hexes` | text | 피해야 할 컬러 HEX 목록 (콤마 구분) |
| `palette_hexes` | text | 추천 팔레트 HEX 6종 (콤마 구분) |
| `note` | rich_text | 저장 시점의 추천 팁 |
| `owner_token` | text | 브라우저별 소유 식별 토큰 |
| `created_at` | datetime | 저장 시각 |

> `owner_token`은 인증 수단이 아니라 브라우저별 구분용 식별자입니다. 정적 사이트 특성상 서버 인증은 지원하지 않습니다.

## 5. 기능 진입 URI

| 경로 / 앵커 | 설명 |
| --- | --- |
| `/` (`#top`) | 랜딩 · 히어로 |
| `#finder` | 띠 찾기 (연도 입력 · 띠 칩 선택) |
| `#result-anchor` | 띠 컬러 리포트 영역 |
| `#elements` | 오행 이론 섹션 |
| `#food-guide` | 오행별 음식 궁합 섹션 |
| `#catalog` | 12띠 전체 카탈로그 |
| `#archive` | 저장한 카드 목록 |
| `tables/color_cards` | 카드 목록 조회 `GET` |
| `tables/color_cards/{id}` | 카드 삭제 `DELETE` |
| `tables/color_cards` (`POST`) | 카드 생성 |

## 6. 외부 라이브러리 (CDN)

- Chart.js 4.4.3 — 오행 밸런스 레이더 차트
- Google Fonts (Gowun Batang, Noto Sans KR)

## 7. 아직 구현되지 않은 기능

- 음력/입춘 경계 보정 (현재는 양력 연도 기준 근사)
- 음식 궁합의 개인 건강 상태 반영 (현재는 오행·오미 이론 기준 일반 가이드)
- 궁합·연도별 운세 등 확장 콘텐츠
- 이미지 카드(PNG) 내보내기 및 공유 링크 생성
- 서버 사이드 인증 기반 개인화 (정적 사이트 한계)
